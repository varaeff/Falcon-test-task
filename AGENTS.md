# Правила разработки

- Используй TypeScript, Vue 3 и Tailwind CSS при написании кода.
- При вёрстке используй подход mobile-first.
- Не используй тип `any`.
- Следуй принципам KISS, DRY и SOLID.
- Создавай «глупые» компоненты: оставляй в них только логику представления.
- Поддерживай компоненты небольшими и размещай в каждом минимум необходимого кода.
- Выноси бизнес-логику и API-запросы в отдельные слои.
