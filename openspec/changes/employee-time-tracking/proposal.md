## Why

Компании нужен простой общий учёт рабочего времени сотрудников с сохранением данных между сеансами и устройствами. Тестовое приложение должно позволять вести задачи и получать отчёты без собственного серверного приложения.

## What Changes

- Создать Vue 3 приложение с выбором сотрудника без пароля и одной активной сессией на сотрудника.
- Добавить управление сотрудниками и назначение роли администратора администраторами.
- Реализовать таймеры задач, исправление завершённых записей и отчёты за период.
- Использовать общую базу Supabase и подготовить публикацию на Vercel и инструкцию по настройке.

## Capabilities

### New Capabilities

- `employees-sessions`: сотрудники, роли и вход с вытеснением предыдущей сессии.
- `time-tracking`: таймеры задач и управление собственными записями.
- `time-reports`: отчёты за период для сотрудников и администраторов.

### Modified Capabilities

Нет.

## Impact

Новый клиент Vue 3 с TypeScript, схема PostgreSQL и API Supabase, статический хостинг Vercel, инструкции настройки и проверки. Приложение предполагает доверенную среду тестового задания: выбор имени не подтверждает личность.
