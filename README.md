# Учёт рабочего времени

Тестовое приложение Vue 3 для учёта времени с общей базой Supabase.

## Настройка

1. Создайте проект Supabase и дождитесь его запуска.
2. Выполните содержимое `supabase/migrations/20261030000000_time_tracking.sql` в SQL Editor проекта. Миграция создаёт сотрудника «Администратор» с ролью администратора. При необходимости измените имя в миграции до её применения.
3. Скопируйте `.env.example` в `.env.local`, укажите `VITE_SUPABASE_URL` и публичный `VITE_SUPABASE_ANON_KEY` из настроек проекта. Не используйте service role key в клиенте. Пароли и другие секреты не должны иметь префикс `VITE_`: Vite предоставляет такие переменные клиентскому коду.
4. Выполните `npm ci`, затем `npm run dev`. Проверки: `npm test` и `npm run build`.

Для Vercel импортируйте репозиторий, задайте те же публичные переменные окружения и запустите развёртывание. `vercel.json` задаёт сборку и каталог результата. Убедитесь, что Supabase доступен: бесплатный проект может быть приостановлен и потребовать восстановления в панели Supabase. Для отката приложения выберите предыдущую сборку Vercel; данные базы автоматически не удаляются.

## Ограничения безопасности

Вход по имени не подтверждает личность. Любой, кто имеет доступ к приложению и публичному API, может войти как любой сотрудник, в том числе администратор. Проверки сессии и роли защищают обычный сценарий работы, но не заменяют аутентификацию и защиту от поддельных запросов. Решение предназначено только для демонстрации в доверенной среде, не для реальных чувствительных данных. Для эксплуатации необходимы полноценная аутентификация и правила доступа.

Отчёт использует часовой пояс устройства; результаты за одинаковые календарные даты в разных поясах могут отличаться. Таймер продолжает идти при закрытии страницы и отсутствии сети, но для сохранения действий требуется соединение.
